# 复刻提示词（中文）

> 以下是根据最终成品整理的完整复刻提示词，可直接粘给 AI，让它从零生成同款的单文件 three.js 场景。

你是一名擅长 three.js 与风格化场景的前端工程师。请用**一个 HTML 文件**做出一个可交互的立体草原微缩场景，风格是“手绘纸艺 / 软陶模型”，不要写实渲染。

## 硬性约束

- 只交付一个 index.html，双击即可打开；three.js 0.160 通过 importmap 从 unpkg 加载，并使用 OrbitControls；不要构建步骤，不要 npm。
- 所有纹理（草地、田土、岛屿遮罩）都用 Canvas 2D 程序化生成；不引用任何外部图片、模型或字体文件。
- 页面需要联网加载 three.js；断网时显示简体中文兜底提示。
- 所有界面可见文案使用简体中文。

## 画面与构图

- 44 × 29 m 的圆角矩形草皮岛，边缘用 Canvas alpha 毛边遮罩，露出深绿色薄侧壁，像一块浮起来的草皮；草皮边缘混一点奶油色。
- 相机放在 (0, 52.5, 34.5)，看向 (0, 2, 0)，FOV 35；必须是正面高俯视，不要 45° 侧看，否则矩形草皮会变成菱形并被裁切。
- 暖色平行光 + 半球光，ACES 色调映射，VSM 软阴影（2048，blurSamples 12），再加一层页面暗角。
- 场景元素：8 棵树（其中一棵紫色）、3 块石头、3 朵云；一条从左下到右上的河、一条米色土路、右下一块稻田。

## 草皮与地表

- 2048 × 1400 的手绘草地纹理：浅绿底、深浅草叶笔触、泥土色小径、零散小黄花香点。
- 岛形遮罩用圆角矩形 + 抖动轮廓 + 模糊毛边；把遮罩通过 onBeforeCompile 注入草地、河流、道路的 shader，让它们都在岛边渐隐。
- 河道和道路用 CatmullRom 曲线 + ribbon 几何，边缘柔和，不能伸出草皮。

## 河流

- 水面用自定义 ShaderMaterial：两层噪声沿 v 方向向下游滚动，形成顺流波纹；带淡蓝色 glint、岸边泡沫、低强度太阳反光。
- 用岛屿遮罩裁掉河岸外的水面；水面是饱和的蓝色，不要大面积 PBR 白色高光。
- 风会影响水面：起伏、流速、亮纹和泡沫略有变化，但必须保持连续顺滑，不能出现白色碎斜线。

## 稻田

- 稻田是一块有机形状的低矮田块，比周围草地高约 7 cm，边缘平滑收平。
- 田里铺约 3200 株实例化稻丛：每株由 8 片深绿叶片（0.6–0.95 m，向外微弯）和 3 个交叉 ribbon 稻穗组成；稻穗从植株上方拱起再下垂，颜色是琥珀金，叶尖略亮。
- 稻丛用 InstancedMesh；关闭 castShadow 和 receiveShadow，避免脏灰；用顶点着色器做风摆，叶片和稻穗顺风弯，并有行波。
- 田面用金色田土纹理，保留少量田土露出来；不要用写实贴图。
- 羊的漫游目标要避开稻田。

## 羊

- 11 只羊，奶油色毛球身体、黑色脸、短腿；层级严格为 root → bob → body / neck / legs[4] / tail；整体缩放 1.25。
- 行为状态机：待机、吃草、行走、跳跃。跳跃总时长约 0.82 秒，世界高度顶点约 0.62 m，落地回到待机；跳跃时身体做 squash/stretch，腿在腾空时收起。
- 羊要能投影，也要接收阴影；羊脚下可以有一小块很淡的接触阴影。

## 交互

- 左键点击羊：选中，出现 8 个控制点、蓝色标签（宽 × 高 米 · 距离 米）和工具栏（待机 / 吃草 / 行走 / 跳跃 | 撤销 / 重做 / 复制 / 删除）。
- 拖动蓝色选择框：平移羊，拖动时相机不旋转。
- 在草地上按住左键画圈：松开后生成一只新羊，位置在该区域，且不要和已有羊重叠。
- 空白处左键拖或右键拖：旋转视角；滚轮缩放；Ctrl/Cmd+Z 撤销，加 Shift 重做。
- 所有交互都要有指针状态、按钮禁用态和历史栈；复制后数量 +1，删除后数量 −1。

## 风场

- 全局风场：基础强度每 2–6 秒随机换一次（约 0.05–1.2），方向缓慢摆动，叠加阵风噪声。
- 树叶 / 稻叶 / 稻穗等轻物始终随风摆动；树干等重物只在风力超过 0.5 时轻微倾斜（最大约 3.4°），小风时必须保持 0。
- 树的 yaw 是随机的，施加风旋转前要把世界风向转到树的局部空间。
- 河面、稻子、树都接同一个风，保证风感和方向一致。

## 验收

- 双击 index.html 能直接打开；控制台 0 报错；页面需要联网。
- 岛是圆角草皮，边缘有毛边，河流/道路不伸出岛。
- 点羊出现 8 个控制点、标签和工具栏；拖动框能移动羊；空白点击取消选择；圈选能生成新羊且不重叠；撤销/重做/复制/删除都能用。
- 跳跃世界顶点约 0.62 m、总时长约 0.82 s，落地回到待机。
- 小风时树干角度为 0，树冠会动；强风时树干才轻微倾斜；稻子和河面有风感。
- 界面文字全部为简体中文。
